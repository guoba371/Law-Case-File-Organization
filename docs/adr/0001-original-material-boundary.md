# 原始材料与身份映射留在律所受控环境

2026-10-31 用户对原卷处理环境回复“按照建议来”，据此确认：原始 PDF、未脱敏 OCR、身份映射及其未脱敏派生内容留在本所电脑或受控环境；仅将针对用途、接收方和确定版本复核批准的脱敏内容交给获批 SaaS/模型。相较原卷直接进入云端，此方案增加本所侧处理与协作成本，但避免默认向外部服务交付原始内容。

接受的是数据边界，不是完整技术架构或真实案卷外发许可。浏览器本地处理、本地组件或本所服务器仍需选型，具体供应商也未获准入批准；原卷预览、OCR、临时文件及身份映射不能通过云 OCR、日志、备份或客服附件绕过该边界。

被比较的方案包括原卷云端处理、律所侧处理加 SaaS、完整私有部署。未来如需允许原卷进入外部云，应单独修订此决策并重新评审责任、存储、权限、删除和供应商边界，不增加默认上传开关。当前决定并不宣称产品已经实现。
