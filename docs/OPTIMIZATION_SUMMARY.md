# 基础设施更新说明

本文记录本次加入的服务端基础模块及其当前边界，不代表生产安全审计或部署认证。

## 本次更新

- `src/config.js` 集中管理服务监听地址、端口、静态目录、日志级别和一般 API 限流值。模型密钥仍由供应商模块读取环境变量或本地设置文件；服务启动不要求预先配置密钥。
- `src/logger.js` 记录请求路径、状态码和耗时，过滤 `apiKey`、密码、token、secret、authorization 等敏感字段；生产模式日志写入 `data/logs/`。
- `src/errors.js` 提供应用错误类、输入验证工具和统一错误响应处理。现有业务接口仍有部分直接抛出普通 `Error`，其默认响应状态保持为 `400`。
- `src/rate-limiter.js` 在进程内按远端 IP 计数，服务器将一般 API、文件接口、案件处理及文书接口分配到不同限制器。它不适用于多实例共享限流，也不提供用户级限流。
- `GET /health` 返回本机服务状态、运行时间、环境和版本。
- ESLint、Prettier 配置及 `npm run validate` 提供静态检查、格式检查和测试入口。

## 运行与验证

```bash
npm install
npm run validate
npm start
```

服务默认绑定 `127.0.0.1`，没有用户身份认证或案件级权限隔离。当前版本仅面向安装服务的本机内部使用，不应直接暴露到公网或未受控的局域网。

## 数据处理边界

- `data/`、`.env`、`.env.local` 已加入忽略规则，不应提交真实案件资料、模型密钥或 SMTP 授权码。
- 案件创建要求操作者确认材料已经脱敏；这只是流程校验，不会自动检测脱敏是否充分。
- 案件分析及文书生成会将相关材料发送给所选模型供应商。提交前应由律师核验内容，并确认供应商的数据处理条款。
- 本模块不提供完整审计日志、自动备份、访问控制或合规认证。
